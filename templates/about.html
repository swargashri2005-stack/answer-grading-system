GradeSense

GradeSense AI is an intelligent academic grading platform designed to evaluate written responses using natural language processing and similarity-based analysis. It helps educators compare student answers with reference solutions and identify performance trends quickly and consistently.

The system supports streamlined question management, student record handling, answer submission, and automated scoring using multiple algorithms such as Jaccard, TF-IDF, Word2Vec, and SBERT.

Project Objective

To reduce manual grading effort while improving consistency, speed, and analytical insight.

  • Automated answer comparison
  • Reference-based evaluation
  • Multi-model scoring workflow
  • Teacher-friendly reporting

Smart Evaluation

Uses multiple NLP methods to estimate answer similarity and support fairer scoring decisions.

Teacher Workflow

Simple interface for managing questions, students, reference answers, and grading runs.

Scalable Design

Built as a foundation for future enhancements like rubrics, dashboards, and analytics.
